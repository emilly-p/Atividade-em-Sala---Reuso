# Atividade-em-Sala---Reuso
Atividade feita em sala de aula utilizando a linguagem de programção Java, para a aula de Programação Orientada a Objeto.
O domínio do trabalho é Escola de Musica, possuindo como classes principais a superclasse Músicos e as subclasses Aluno e Professor, que herdam as característica da primeira.
Informações do projeto:
*Dominio: Escola de musica
Classes: Musicos(Superclasse), Aluno e professor(subclasses) 
A principal ideia é que a classse música possua as caracteristicas gerais dos membros da escola, sendo seus atributos: 
 identidade, idade, tempo na escola, e tipo de instrumento que toca(sendo esse o elemento que ira utilizar override).
 Já para as subclasses aluno e professor, os atributos individuais serão:
 Alunos: Numero de matricula, mensalidade, media de notas;
 Professores: Salario, anos de experiencia, formação.
 A classe musico será uma classe abstrata, e o metodo sobrescrito será o instrumento que cada um toca, sendo individual.

 Considerações após uma hora de fazer o trabalho: problemas em override, necessidade de mais tempo para a finalizaçaõ do trabalho.
